# 🌐 GitHub Pages 배포 가이드

## 자동 배포 완료! 이제 GitHub에서 2단계만 설정하면 됩니다.

### ✅ 1단계: GitHub 저장소 접속

브라우저에서 다음 주소로 이동:
```
https://github.com/juwon24/agent_claude
```

### ✅ 2단계: GitHub Pages 활성화

1. 저장소 상단의 **`Settings`** (⚙️ 톱니바퀴) 탭 클릭

2. 왼쪽 사이드바에서 **`Pages`** 클릭

3. **Source** 섹션에서:
   - `Deploy from a branch` → **`GitHub Actions`** 로 변경

4. 저장 완료!

### 🎉 3단계: 접속하기

설정 후 1-2분 정도 기다리면 자동으로 배포됩니다.

접속 URL:
```
https://juwon24.github.io/agent_claude/
```

또는

```
https://juwon24.github.io/agent_claude/index.html
```

---

## 📱 배포 상태 확인

1. GitHub 저장소에서 **`Actions`** 탭 클릭
2. "Deploy Digital Core Simulator to GitHub Pages" 워크플로우 확인
3. 초록색 체크 표시(✅)가 나오면 배포 완료!

---

## 🔧 문제 해결

### "404 Not Found" 에러가 나타나면?

**원인**: GitHub Pages가 아직 활성화되지 않음

**해결책**: 위의 2단계를 다시 확인하세요.

1. Settings → Pages
2. Source를 **GitHub Actions**로 변경
3. 1-2분 대기

### Actions가 실패하면?

**원인**: Pages 권한이 없음

**해결책**:
1. Settings → Pages → Source를 **GitHub Actions**로 설정
2. Settings → Actions → General
3. "Workflow permissions" 섹션에서 **Read and write permissions** 선택
4. 저장 후 Actions 탭에서 워크플로우 다시 실행
