# 🚀 빠른 시작 가이드 (Quick Start Guide)

## 5분 안에 시작하기

### 1단계: 데이터 생성 (이미 완료되어 있음)

```bash
python generate_rock_data.py
```

✅ `data/rock_properties_data.json` 파일이 생성됨

### 2단계: 웹 서버 실행

가장 간단한 방법:

```bash
python -m http.server 8000
```

### 3단계: 브라우저 열기

```
http://localhost:8000
```

## 🎮 첫 번째 사용

1. **암석 타입 선택**: 드롭다운에서 "Sandstone" 선택
2. **샘플 클릭**: 자동으로 생성된 샘플 중 하나 클릭
3. **3D 모델 회전**: 마우스로 드래그해서 코어 모델 회전
4. **공극률 조절**: 슬라이더를 움직여서 실시간 변화 관찰

## 📱 화면 구성

```
┌─────────────────────────────────────────────────────┐

│  패널    │  응력-변형률  │  공극률-투수율  │ 속도  │
│          │     곡선      │      관계      │ 관계  │
└──────────┴──────────────────────────────────────────┘
```

## 💡 팁

- **암석별 특징 비교**
  - Granite (화강암): 낮은 공극률, 높은 강도
  - Sandstone (사암): 높은 공극률, 중간 강도
  - Shale (셰일): 낮은 투수율

- **물성 관계 이해**
  - 공극률 ↑ → 투수율 ↑ (3제곱 비례)
  - 공극률 ↑ → 탄성파속도 ↓
  - 공극률 ↑ → 압축강도 ↓

## 🔧 문제 해결

### 데이터가 로드되지 않음
→ 웹 서버를 통해 실행했는지 확인 (파일 직접 열기는 불가)

### 3D 모델이 보이지 않음
→ 브라우저가 WebGL을 지원하는지 확인 (최신 Chrome/Firefox 권장)

### 차트가 업데이트되지 않음
→ 먼저 암석 타입을 선택했는지 확인
